# Lazy Person Startup Apps

A personal Electron desktop app that launches your preset apps and websites with a single click — pick your mode and everything opens automatically.

## Modes

| Mode | What it launches |
|------|-----------------|
| **Game** | Spotify, Discord, Bilibili, Steam |
| **Coding** | Spotify, VS Code, Steam (game), Claude AI |
| **Study** | Chrome → Taylor's University portal |

## Tech Stack

- Electron
- React + TypeScript
- Vite
- Tailwind CSS

## Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Outputs a Windows installer to `release/`.
